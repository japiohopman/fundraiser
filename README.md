# ParkNest Fundraiser Transparency

An independent static information site documenting the crowdfunding actions connected to the August 2026 ParkNest fire in Amsterdam-Oost.

The goal is clarity: explain what happened, identify the different fundraising actions, distinguish collective ParkNest fundraising from personal loss/recovery campaigns, and link visitors directly to the original sources.

## Current phase

The repository is in the **evidence and content foundation** phase. The visual site is deliberately not being built until the known fundraising actions have a source-backed description.

### Project documents

- [`docs/story.md`](docs/story.md) — project purpose, story and neutral framing
- [`docs/fundraisers.md`](docs/fundraisers.md) — canonical fundraiser/source register
- [`docs/editorial-policy.md`](docs/editorial-policy.md) — rules for factual and transparent publishing
- [`docs/roadmap.md`](docs/roadmap.md) — implementation roadmap and open questions
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — branch and content workflow

## Working principle

> **One fire. Multiple fundraising actions. A clear view of what each one is for.**

This site is independent. It does not manage the listed fundraisers and must not present itself as the official ParkNest website.

## Development workflow

Normal work happens on a focused branch and reaches `main` through a reviewed pull request. GitHub Actions already contains a foundation check; it will be expanded when the application scaffold is added.
