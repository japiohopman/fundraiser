# ParkNest Fundraiser Transparency

An independent static information site documenting the crowdfunding actions connected to the August 2026 ParkNest fire in Amsterdam-Oost.

The goal is clarity: explain what happened, identify the different fundraising actions, distinguish collective ParkNest fundraising from personal loss/recovery campaigns, and link visitors directly to the original sources.

This repository is intentionally starting from an empty foundation. The first project phase will establish the factual story, fundraiser register, content rules, and delivery workflow before the visual site is built.
